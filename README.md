This web application is used for tracking your personal incomes and expenses. It allows you to see all your transactions and balance from selected period.<br>
Features:<br>
-adding expenses and incomes<br>
-adding/removing categories<br>
-set limits for each category<br>
-show balance for selected period and graphs<br>
